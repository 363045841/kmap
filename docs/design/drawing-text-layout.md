# 绘图文本换行

## 背景

绘图附属文本此前直接传给 Canvas `fillText`。长文本会穿过图元和视口边界，且用户编辑、Agent 工具调用和导入数据对换行的表示没有统一约束。

## 决策

绘图文档的 `DrawingLabel.text` 使用字面量 `\n` 作为唯一持久化换行控制码。

- 用户在编辑器按 Enter 后，`DrawingDocument` 将 LF 或 CRLF 规范化为 `\n`。
- Agent 工具和导入数据直接使用 `\n`。
- `DrawingDocument` 是唯一的规范化边界，创建、更新和整份替换都经过它。
- 渲染前只将 `\n` 拆成逻辑行；不保存真实换行符。

渲染器只按 `\n` 拆分逻辑行，不以图元尺寸、视口尺寸或字符宽度自动折行。文本的行数和每行内容完全由用户或 Agent 输入的 `\n` 决定。

线和箭头标签仍保持其旋转和语义位置；区域、点和独立文本按其既有锚点绘制。文本不限制行数，也不截断。
