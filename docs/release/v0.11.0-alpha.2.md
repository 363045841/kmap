# 相比 v0.11.0-alpha.1 的变更 / Changes since v0.11.0-alpha.1

## ✨ 新功能 / Features

- **绘图工具支持子图与分时绘图,带 workspace 隔离**: Drawing tools now support sub-pane and time-share drawings with workspace isolation.
- **多选、批量编辑、时间锚点投影**: Multi-selection, batch editing and time-anchor projection for drawings.
- **空白区域锚点支持**: Drawings can now anchor in the right blank area of the chart.
- **单行内联文本编辑**: Per-line inline text editing on drawings.
- **框选与成组拖拽**: Marquee box-select with group drag for drawings.
- **绘图线条标签位置可配置**: Configurable line label position on drawings.
- **图表上下文注入 + Provider 自定义请求头**: Chart context injection, provider custom request headers & drawing labels (#151).
- **Agent 工具支持自定义 Provider 请求头**: Custom provider request headers on Agent tools.
- **向运行上下文注入选区 K 线**: Inject selected range K-lines into run context.
- **向图表上下文注入时区感知日期**: Inject timezone-aware dates into chart context.
- **由市场交易日驱动 Agent 上下文与工具**: Drive context and tools by market trading dates.
- **向模型上下文注入当前标的与选区**: Inject current symbol and selected range into model context.
- **主指标 CRUD 归一化,补齐 Agent 工具**: Normalize main indicator CRUD and add agent tools.
- **避免提示框与十字光标轴重叠**: Avoid tooltip overlapping the crosshair axis in adaptive mode.
- **Agent 工具调用上限提升至 20 轮**: Raise tool turn limit to 20.
- **Agent 工具失败详情渲染,移除每工具重试**: Render tool failure details and drop per-tool retry.

## 🐛 Bug 修复 / Fixes

- **视口禁止滚入完全空的尾部区域**: Prevent scrolling into fully empty trailing area.
- **绘图层渲染到 Overlay 画布,保持在 GPU K 线之上**: Render drawing layer on overlay canvas to stay above GPU K-line.
- **平移时隐藏十字光标,释放后恢复**: Hide crosshair during pan and restore after release.
- **统一滚动投影,修复 WebGL mediump 精度问题**: Unify scroll projection and fix WebGL mediump precision (#150).
- **统一帧 X 投影与 WebGL 滚动精度**: Unify frame X projection and WebGL scroll precision.
- **修复 Chrome 移动端顶部标签栏导致的显示问题**: Display issues caused by the top tab bar in Chrome on mobile.
- **修复预览入口引入滚动条样式以避免被摇树删除**: Keep global scrollbar css from being tree-shaken at the preview entry.
- **子图内容替换时归一化 VOL 别名**: Normalize VOL alias on sub-pane content replacement.
- **绘图单一时间轴锚点不再伪造 X 坐标**: Model single-axis anchors without fake X.
- **下拉菜单外部点击与指标默认值修正**: Correct dropdown outside click and indicator defaults.

## 🏗️ 架构与重构 / Architecture & Refactoring

- **绘图标签统一走完整模型快照提交**: Commit labels via full model snapshots.
- **禁止向 Agent 工具直接传入时间戳**: Forbid timestamp inputs on Agent tools.
- **Chart 平面 API 按领域门面归组**: Group Chart flat API into domain facades.
- **统一数据视图模型,明确绘图锚点类型**: Unify data-view model and clarify drawing anchor types.
- **交互锚点必须带时间戳**: Require timestamp on interaction anchors.
- **快照派生保持纯函数,统一指标时序**: Keep snapshot derivation pure and unify indicator timing.
- **WebGL 共享面强制显式帧生命周期**: Enforce explicit frame lifecycle on shared surface.
- **WebGL 场景直接绘制到可见画布而非合成到 2D**: Render WebGL scene on a visible canvas instead of compositing to 2D.
- **探测函数简化,修正 selectBackend 注释**: Simplify probe functions and fix selectBackend comment.
- **绘图投影复用可见数据切片与 toScreen 闭包**: Reuse visibleData slice and toScreen closure across frame projection.
- **Vue 高频交互迁出 VDOM**: Move high-frequency interactions out of the VDOM.
- **视口编程滚动回环走 bridge 通道**: Consume programmatic scroll event loopback via bridge.
- **原生滚动在渲染帧事务内提交**: Commit native scroll inside the render frame transaction.
- **Agent 运行时契约与交易日处理简化**: Simplify runtime contract and trading date handling.
- **主指标管理器收敛,公共面收窄**: Simplify main indicator manager and narrow public surface.
